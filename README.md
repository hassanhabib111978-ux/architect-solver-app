# مساعد البدائل الهندسية والمعمارية

تطبيق Flutter أولي يساعد المهندس أو المقاول على تنظيم وصف المشكلة ومقارنة بدائل مبدئية من حيث التكلفة والجودة وسرعة التنفيذ.

## الحالة الحالية
- تم إعداد هيكل Flutter والواجهات الأساسية.
- شاشة إدخال وصف المشكلة.
- شاشة عرض البدائل الثلاثة عند توفر خادم API.
- حاسبة فرق التكلفة البسيطة.
- صفحة إرشادات السلامة.
- إعداد GitHub Actions لبناء APK تجريبي.

## تشغيل المشروع
```bash
flutter pub get
flutter run
```

## ربط خدمة الذكاء الاصطناعي
لا يوضع مفتاح OpenAI أو أي مفتاح سري داخل التطبيق. يجب إنشاء خادم وسيط آمن ثم تمرير عنوانه وقت البناء:

```bash
flutter run --dart-define=API_BASE_URL=https://YOUR-SERVER.example
```

يتوقع التطبيق وجود المسار:
`POST /v1/engineering/alternatives`

ويُرسل JSON يتضمن `description` و`project_type` و`location`. يجب أن يعيد الخادم كائن JSON يحتوي على `alternatives`، وهي قائمة من ثلاثة بدائل، ولكل بديل الحقول:
`title`, `category`, `description`, `advantages`, `disadvantages`, `estimated_cost`, `estimated_duration`, `safety_notes`.

## تنبيه هندسي
المخرجات إرشادية أولية وليست تصميماً تنفيذياً أو اعتماداً هندسياً. لا تُنفذ أعمال الأساسات أو العناصر الإنشائية أو التدعيم أو القص أو الثقب أو معالجة التربة اعتماداً على التطبيق وحده. يلزم الرجوع إلى المخططات والاختبارات والكود المحلي ومهندس مختص مسؤول عن الموقع.

## ملاحظات قبل النشر
هذه نسخة تأسيسية وليست إصداراً إنتاجياً. يلزم إعداد الخادم الآمن، واختبار الأجهزة، وإضافة الخط العربي المضمّن لتصدير PDF بالعربية، وإعداد هوية التطبيق وتوقيع إصدار Android قبل النشر على Google Play.
