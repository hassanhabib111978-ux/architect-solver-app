# مساعد البدائل الهندسية والمعمارية

تطبيق Flutter أولي يساعد المهندس أو المقاول على تنظيم وصف المشكلة ومقارنة بدائل مبدئية من حيث التكلفة والجودة وسرعة التنفيذ.

## الوظائف الموجودة في النسخة الحالية
- إدخال نوع المشروع ووصف الحالة وموقعها.
- شاشة مقارنة ثلاثة بدائل عند توفر خادم API.
- التقاط صورة للموقع بالكاميرا أو اختيارها من المعرض.
- إرسال الصورة للتحليل عبر خادم وسيط آمن (بعد إعداد الخادم).
- سجل محلي للحالات باستخدام SQLite.
- حاسبة فرق التكلفة.
- دليل إرشادي أولي للسلامة.
- فحص Dart واختبارات واجهة وبناء APK تجريبي عبر GitHub Actions.

## تشغيل المشروع
```bash
flutter pub get
flutter run
```

## واجهة الخادم المطلوبة
لا يوضع مفتاح OpenAI أو أي مفتاح سري داخل التطبيق. يجب إعداد خادم وسيط آمن ثم تمرير عنوانه وقت البناء:

```bash
flutter run --dart-define=API_BASE_URL=https://YOUR-SERVER.example
```

### توليد البدائل
المسار: `POST /v1/engineering/alternatives`

الطلب JSON:
```json
{
  "description": "وصف الحالة",
  "project_type": "مبنى سكني",
  "location": "المدينة أو المنطقة"
}
```

يجب أن يعيد الخادم كائن JSON يحتوي على `alternatives`، وهي قائمة من ثلاثة بدائل، ولكل بديل الحقول:
`title`, `category`, `description`, `advantages`, `disadvantages`, `estimated_cost`, `estimated_duration`, `safety_notes`.

### تحليل صورة الموقع
المسار: `POST /v1/engineering/site-image`

الطلب JSON يحتوي على:
- `image_base64`: بيانات الصورة بترميز Base64.
- `mime_type`: نوع الصورة.
- `site_notes`: ملاحظات المستخدم.

الاستجابة يجب أن تحتوي على نص في أحد الحقول: `analysis` أو `report` أو `result`.

## تنبيه هندسي
المخرجات إرشادية أولية وليست تصميماً تنفيذياً أو اعتماداً هندسياً. لا تُنفذ أعمال الأساسات أو العناصر الإنشائية أو التدعيم أو القص أو الثقب أو معالجة التربة اعتماداً على التطبيق وحده. لا يمكن تشخيص سلامة المنشأ أو سبب الشقوق من صورة فقط؛ يلزم الرجوع إلى المخططات والاختبارات والكود المحلي ومهندس مختص مسؤول عن الموقع.

## ما يزال مطلوباً قبل الإطلاق
- إنشاء خادم API فعلي وتأمينه بمفتاح محفوظ في الخادم لا في التطبيق.
- ربط الخادم بنموذج الرؤية واللغة واختبار شكل الاستجابات.
- تضمين خط عربي مناسب قبل اعتماد تصدير PDF بالعربية.
- اختبارات على أجهزة Android فعلية ومعالجة حالات انقطاع الاتصال.
- إعداد أيقونة التطبيق واسم الحزمة النهائي وتوقيع إصدار Release قبل النشر على Google Play.

هذه نسخة تأسيسية قيد التطوير وليست إصداراً إنتاجياً.
